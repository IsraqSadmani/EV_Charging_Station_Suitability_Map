# Potential Khas Land for EV Charging Stations – Dhaka City

An interactive web map showing khas land plots in Dhaka City identified as
potential sites for electric vehicle (EV) charging stations.

**Live map:** https://yourusername.github.io/ev-khas-land-map/

## Suitability classes
| Class  | Colour |
|--------|--------|
| High   | Green  |
| Medium | Orange |
| Low    | Red    |

## Features
- Plots labelled by JL_Sh_Plot (JL No_Sheet No_Plot No)
- Click a plot to see mauza, JL/sheet/plot number, survey version, area (katha), current use and administrative units
- Filter by suitability class and search by JL_Sh_Plot
- Switchable basemaps: Google Streets/Satellite/Hybrid, OpenStreetMap, CartoDB Positron, Esri World Imagery

## Data
40 candidate plots across Dhaka.

## Built with
[Leaflet](https://leafletjs.com/)
